# 쏙!

젤 패드에서 비즈를 하나씩 **쏙** 뽑는 손맛 미니게임. 모바일 브라우저 우선.

이 프로젝트의 핵심은 기능 개수가 아니라 **촉감의 착각**이다 — 젤을 누르고, 벌리고, 비즈를 잡고, 저항을 느끼며 당기다가, 툭 하고 빠지는 순간.

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:5173  (--host 로 같은 Wi-Fi의 폰에서 접속 가능)
pnpm build        # 타입체크 + dist/ 빌드
pnpm preview      # 빌드 결과 미리보기 (4173)
```

`main`에 push하면 GitHub Actions가 빌드 결과를 `gh-pages` 브랜치로 밀어 GitHub Pages에 배포한다 (`.github/workflows/deploy.yml`).

배포 주소: **https://sbp37.github.io/ssok/**

## 테스트 / 튜닝

- **`?pad=donut`** — 특정 패드로 시작 (`cloud flower donut paw ribbon shell cherry star`). 진행 저장은 `localStorage["ssok.pads.v1"]`.
- **`?test=5`** — 감촉이 다른 다섯 종류(작은 비즈 · 큰 진주 · 별 · 투명 구슬 · 길쭉이)가 넓게 박힌 테스트 패드. 젤 누르기 → 잡기 → 늘리기 → POP → 복원 손맛을 비교할 때 쓴다. (`?test=12` 처럼 개수 지정 가능, 종류는 순환)
- 브라우저 콘솔에서 `window.__ssok` 으로 Game 인스턴스에 접근할 수 있다.
  - `__ssok.debugBeads()` — 잡을 수 있는 비즈의 화면 좌표와 임계 거리(`t1`, `t2`)
  - `__ssok.gel` — 젤 상태 (fingers, wobble, shocks, R)
- 소리는 첫 터치 이후에 켜진다(브라우저 정책). 진동은 Android Chrome에서만 동작한다.
- **효과음 샘플 교체**: `public/sfx/manifest.json`의 `samples`에 이름 → 파일을 적고 같은 폴더에 파일을 두면 그 소리만 녹음 샘플로 바뀐다. 이름: `press, stretch, tick, pop_small, pop_big, release, land_glass, land_plastic, land_metal, land_shell, rare`. 없는 이름은 프로시저럴 소리로 폴백. 재생 때마다 pitch/volume이 ±7~10% 흔들린다.

### 패드 · NEXT · 숨은 오브젝트

- 8종 패드(구름 → 꽃 → 도넛 → 발바닥 → 리본 → 조개 → 체리 → 별). 코드는 하나, `PadType` 데이터만 다르다. 패드마다 **차이는 한 가지**: 구름은 말랑하고 잘 빠짐, 꽃/별은 끝이 얇아 끝쪽 비즈가 쉽게 빠짐, 도넛은 진짜 구멍, 발바닥은 발가락이 말랑, 리본은 매듭이 안 빠짐(가운데 희귀 확률↑), 조개는 진주 많음, 체리는 한쪽을 당기면 반대쪽이 살짝 흔들림.
- 패드마다 **숨은 오브젝트** 1개가 깊은 층 가운데 근처에 묻혀 있다. 일반 비즈보다 크고, 위의 비즈 가장자리로 살짝만 보이다가 패드가 비어갈수록 드러난다. 점수 없음.
- 현재 패드를 **~68% 비우면** 화면 왼쪽 아래에 `NEXT` + 다음 패드의 어두운 실루엣 + `???`가 작게 뜬다. 실루엣 안에서 몇 초마다 한 번 힌트 색이 반짝인다.
- **마지막 비즈**를 뽑으면 팝업 없이 패드가 그대로 남고, 0.5초 뒤 "다 비웠다.", 1초 뒤 `[다음 패드 열기]`. 로딩 화면 없음.
- **mock 광고 게이트**: 처음 4개 패드는 방해 없음. 그 뒤 새 패드가 격패드마다 잠기고 `[지금 열기 · 광고 1회]` / `나중에`가 뜬다. `나중에`는 이미 열어본 패드 중 하나를 대신 연다 — 광고를 안 봐도 게임은 절대 막히지 않는다. 실제 SDK 없음, `MockRewardedProvider`가 0.45초 뒤 성공.

### 보상 (전부 mock — 실제 지급 없음)

- **일반 비즈**: 숫자 안 띄움. 손맛 그대로.
- **레어 비즈**(2~4%: 무지개 유리알·오팔): POP 소리에 벨 한 겹, 0.3초 반짝, 수집통 대신 **오른쪽 위 보물함**으로 날아감. 처음이면 `NEW ✦ 오팔`, 아니면 `오팔 +1` 토스트 1.7초.
- **숨은 보물**: 패드마다 1개, `rewards/rates.ts`의 `HIDDEN_POOLS`에서 **가중 랜덤**(같은 패드라도 매번 다름). 마지막에 뽑으면 `조개 속 대왕 진주 발견` + `처음 발견했어 ✦`.
- **초희귀**(왕관 비즈·홀로그램 별·대왕 투명 오리): 풀에 1%씩 + 아무 패드 깊은 층에 0.6%. 토스트 `뭐야 이거?`.
- **보물함**: 카드 그리드 14칸, 못 찾은 건 검은 실루엣 `???`. 출처는 안 알려줌.
- **다이아 💎**(mock): 랜덤으로 절대 안 나옴. **오늘 미션 3개**(패드 3개 비우기 / 숨은 보물 2개 / 광고로 다음 패드 2회)만 각 💎1. 매일 초기화. `내 다이아 → 포인트로 바꾸기`는 "N P 받을 수 있어요 · 실제 포인트 연동은 준비 중"만 표시 — 지급된 것처럼 보이지 않게.
- **패드 변종**: 다음 패드 선택 시 rare 7% / super 1.2%로 변종(유리 구름, 펄 조개, 유리 리본, 무지개 별…). 색·투명도·레어 비율·저항 중 한 가지만 다름. NEXT에 `희귀 패드가 지나가고 있어 ✦` → `[광고 보고 잡기]` / `그냥 다음`(일반 버전 열림). 이전의 격패드 게이트는 이걸로 대체.
- **보물 힌트 훅**: 68%에 이 패드의 숨은 보물이 처음 보는 것이면 `이 패드 안에 처음 보는 게 있어 → [광고 보고 살짝 보기] / 그냥 뽑기`. 살짝 보기 = 1.8초 선명하게.
- 30초 챌린지는 메인에서 숨김 (`?challenge=1`로 표시). 코드는 그대로.
- 조정할 숫자는 전부 `src/game/rewards/rates.ts`.

### 젤 렌더링 방식

1. **베이스 텍스처** — 측면 벽, 반투명 윗면(중앙 옅고 가장자리 진함), 결, 소켓, 묻힌 비즈, 젤 틴트, 프레넬 림을 오프스크린 캔버스에 한 번 그린다. 비즈를 잡거나/놓거나/뽑을 때만 다시 그린다.
2. **메시 변형** — 매 프레임 22×22 격자의 정점을 `Gel.warp()`(손가락 딤플·드래그, 당기는 비즈 쪽 텐트, POP 충격, 전체 출렁임)로 밀어서 WebGL 삼각형으로 텍스처를 그린다. 실루엣까지 같이 찌그러진다. WebGL이 없으면 Canvas 2D 셀 단위 폴백.
3. **동적 오버레이** — 딤플 음영, 뽑힌 자리 움푹함, 미끄러지는 하이라이트, 당기는 비즈의 구멍/텐트/목, 들려 나오는 비즈는 2D 캔버스에 매 프레임 그린다.
