# 숨은 왕비즈·표현 정리·마지막 알의 마무리

기준 `0b3a71a`, 작업 브랜치 `codex/hidden-bead-cleanup`. 2026-09-13 사용자 최종 승인으로 main 반영 및 기존 Actions 배포를 진행한다.

## 변경한 파일

- `beads/Bead.ts`: 왕비즈는 기존 kingChance로 굴리되 위층에 배치하지 않고 일반 비즈 아래에 숨긴다. 빈 아래층 자리를 우선하며 기존 숨은 보물은 교체하지 않는다. 발견 후에는 기존 slotR/깊이 스프링/뽑기 크기 복원을 사용한다. 일반 추첨에서 pick=0 종류도 확실히 제외한다.
- `beads/BeadSprites.ts`: 분홍색 앞쪽 가림/반사 받침을 제거하고 홈의 아래쪽 돌출 및 하단 젤색 림도 없앴다. 위쪽 밝은 림과 좁은 안쪽 음영은 남긴다. 자개 타원 줄무늬를 넓고 부드러운 색면으로 바꾸고, 마지막 타원 경로를 비즈 테두리로 다시 그리던 문제를 수정했다. 마스크 알파 140 이하는 여전히 제외하되 그 위는 짧은 알파 전이로 계단 가장자리를 줄인다.
- `gel/Gel.ts`: 비원형 소켓 바깥의 원형 radial 음영을 윤곽을 따르는 얕은 음영으로 교체했다. 미세 픽셀 노이즈의 진폭/알파를 낮췄다. 메시, 실리콘 물리 기본값, 넓은 재질 음영은 유지한다.
- `physics/pull.ts`: 무작위 fakeout/너무 빠르게 당겼을 때의 놓침/느린 당김의 강제 슬립백을 없앴다. 필요한 거리까지 당기면 속도와 무관하게 POP. grip→stretch→stick-slip/끼임→POP 및 Spring2 60Hz 이하 서브스텝은 유지한다. 끼임 중 22Hz 미세 떨림은 제거했다.
- `beads/BeadTypes.ts`: 더 이상 적용하지 않는 minSpeed/fakeout을 레거시 값으로 주석에 명시. 카탈로그 숫자, 희귀도/보상값은 바꾸지 않았다.
- `Game.ts`: 덮여 있는 왕비즈는 희미한 미리보기에서도 그리지 않는다. 빈 소켓은 별도 dent 복사본 없이 베이스에 한 번만 그린다. 아문 후 깊이 계수는 0.35→0.385(기존보다 10% 높음), 초기에는 짧은 선명도 보정. 마지막 알 당김에만 작은 반사 2개와 단계별 소리 신호를 준다. 모든 비행 종료와 병 정착 후 기존 완료 이벤트 시점에 짧은 정착과 별 6개를 표시한다.
- `audio/Sfx.ts`: 마지막 당김에 최대 세 단계의 짧고 낮은 공명음. 기존 완료음에는 마지막 맑은 음 하나만 추가했다. 기존 음소거·첫 오디오 unlock·음원 폴백을 따른다.
- `README.md`: 바뀐 뽑기/왕비즈/마무리 설명 갱신.

새 게이지/타이밍 시험, 재시도 벌칙, 보상·광고·해금 시스템은 없다. 저장 스키마와 Collector sleep/충돌은 변경하지 않았다. 새 이미지·패키지를 추가하지 않았다. 사용자 사진은 문제 위치 확인용 참고다.

## 마무리 제약

마지막 POP 시점의 완료 저장은 그대로 즉시 처리한다. 별은 마지막 비즈가 도착하고 기존 수집통이 120ms 정착한 뒤 시작한다. 보물함으로 날아가는 희귀 비즈도 모든 비행이 끝나야 한다. 별은 1.15초 이내에 종료하고 새 패드에서 초기화한다. 모션 감소 환경에서는 추가 정착 반동/별의 이동을 생략하고 짧은 페이드만 사용한다. 기본 게임의 기존 움직임을 전부 비활성화하는 설정은 아니다.

## 검증

macOS 데스크톱 Chrome, 360/390/430px 및 390px DPR 2. 휴대폰 실기기/스피커의 체감 음량은 미검증.

- 강제 kingChance=1의 120개 시드에서 왕비즈 120개 모두 아래층/hidden/host/slotR 정상. 기존 큰 진주 보물 보존, 같은 슬롯의 같은 층 중복 없음. kingChance=0에서는 왕비즈 없음.
- 28종 × 위/아래층 × 속도 0/1/100/2000 = 224개 모델 검사. 모든 종류가 필요한 거리 뒤에 POP, slipped 없음. 잡기만 하고 움직이지 않은 상태에서는 POP 없음.
- 실제 브라우저 입력으로 위 비즈→왕비즈 발견→왕비즈 POP→병 정착→별 순서 확인. 덮인 왕비즈 draw=0, 두 번의 POP 중에는 finale=-1, 완료 이벤트에서 flying=false/settled=true. 별 표시 및 시간 종료/새 패드 초기화 정상. 실행 예외/정상 에셋 HTTP 오류 없음.
- 실제 희귀 오팔 마지막 당김: 충전음 호출 [1,2,3], 보물 획득=1, 완료음=1, 병 수집=0. 모션 감소 환경에서 추가 마무리 반동 없음, 별 시간 종료 정상, 새로고침 후 저장 동일.
- 하트·별·타원 POP 후 10초 시점: sockets=3, dents=0, drawSocket 호출도 각 형태별 정확히 1회. 뒤에 원형 그림자가 없는 실제 게임 화면을 `shaped-holes.png`로 확인했다.
- WebGL 비활성화와 비즈 이미지 요청 실패를 강제한 별도 컨텍스트에서도 Canvas 폴백으로 1개 뽑기/수집 성공, 실행 예외 없음.
- 처음 검사에서 짧은 flying 상태만 기다려 시간 초과했다. 진단 결과 비즈는 이미 collected였고 왕비즈가 정상적으로 올라와 있었다. 검사를 flying 또는 collected로 바꿔 위 흐름을 다시 통과했다.

타입 검사와 빌드(`pnpm --config.verifyDepsBeforeRun=false run typecheck`, `pnpm --config.verifyDepsBeforeRun=false run build`) 및 `git diff --check` 통과. 빌드 54모듈, JS 312.16kB / gzip 101.10kB. 작업 환경 부하가 높아 프레임 성능 비교 수치는 제시하지 않는다. 60fps 보장은 아니다.
