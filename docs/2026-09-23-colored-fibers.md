# 컬러 실 뽑기 실험

이 문서는 최초 실 뽑기 구현 기록이다. 이후 판별 배치는 [촉감 변화 구현](2026-09-24-tactile-variety.md)의 구슬 줄→젤 막→컬러 실 순환으로 확장했다.

기준 커밋: `cf9259f`. 작업 브랜치: `codex/colored-fibers`.
main / GitHub Pages / 토스에는 이 실험을 배포하지 않았다.

## 동작

- 첫 판은 기존 비즈만 나온다. 두 번째 판부터 일반 비즈 최대 3개를 분홍·민트·라일락 실로 대체한다. 총 뽑기 횟수를 늘리지 않는다.
- 보물, 왕비즈, 아래층 비즈와 그 위를 가리는 비즈는 대체하지 않는다.
- 실 끝을 손으로 잡아 길게 당긴다. 당긴 길이만큼 묻힌 부분이 나오고, 가만히 잡고 있는 것으로는 완료되지 않는다.
- 놓거나 포인터가 취소되거나 화면이 회전해도 이미 꺼낸 길이는 유지한다. 다시 잡아 이어서 뽑는다.
- 다 나온 실은 짧게 말려 기존 수집통으로 이동한다. 기존 완료·저장 이벤트를 한 번만 사용한다.
- 일반 비즈의 Pull, Spring2, Collector 충돌·sleep, 광고·프로모션 코드는 변경하지 않았다.

## 변경 파일

- `src/game/fibers/Fiber.ts`: 안전한 대체 슬롯 선택, 길이 기반 추출, 재잡기와 느슨한 실 곡선.
- `src/game/fibers/FiberRenderer.ts`: 묻힌 실, 좁은 흔적, 노출된 긴 실과 말린 실의 Canvas 렌더링.
- `src/game/beads/Bead.ts`: 선택적인 실 상태 타입.
- `src/game/Game.ts`: 생성·입력·렌더링과 기존 POP/완료 흐름 연결.
- `src/game/collector/Collector.ts`: 실 항목의 그림만 변경. 물리는 유지.
- `tests/fibers.mjs`: 생성 및 추출 상태 회귀 검사.
- `README.md`: 개발 미리보기와 테스트 안내.

## 검증 방법

- `pnpm build` (TypeScript 검사 포함).
- `node tests/fibers.mjs`: 990개 배치, 총 개수 유지, 보물/숨은 비즈 보호, 경계, 놓기/재잡기, 정지 시 진행 없음, 빠른 스와이프 길이 제한.
- `node tests/round-pacing.mjs`, `node tests/ad-policy.mjs`, `node tests/sprite-cache.mjs`.
- 데스크톱 Chrome / DPR 2 / 360·390·430 × 844. 격리된 브라우저 저장소에서 실제 포인터로 플레이한다.
- 390px에서는 일반 비즈를 모두 뽑은 뒤 마지막 실로 완료, 다음 패드, 새로고침 후 완료 기록 유지까지 확인한다.
- 별도 모바일 터치 에뮬레이션에서 실+비즈 동시 조작과 빠른 스와이프를 검사한다. WebGL을 끄고 비즈 이미지 요청을 차단하여 Canvas/스프라이트 폴백도 확인한다.
- 검증 스크립트와 실제 캡처는 `output/playwright/fibers-*`에 있다. 기존 사용자 저장소는 변경하지 않는다.

검증 결과: 위 명령 모두 통과. 최종 3개 화면 너비에서 런타임 오류·실패한 에셋 요청·가로 넘침 0건.
390px 전체 플레이는 23회 뽑기, 완료 이벤트 1회, 완료 기록 1→2, 수집통의 실 3개를 확인했다.
터치/폴백 검사는 실+비즈 동시 잡기, 부분 추출 유지, 단일 빠른 스와이프 완료를 통과했다.
이 결과는 데스크톱 Chrome 에뮬레이션의 기능 검증이며 실기기 성능 측정이 아니다.

## 한계 / 미배포 확인

- 실기기 안드로이드·iOS·토스에서는 아직 검증하지 않았다. 실제 햅틱·오디오 품질과 60fps를 보장하지 않는다.
- 실은 해석적으로 만든 곡선이다. 완전한 로프 충돌 시뮬레이션이나 실 전용 녹음은 추가하지 않았다.
- 새로고침하면 진행 중 패드가 다시 생성되는 기존 정책을 따른다. 부분적으로 꺼낸 실만 별도로 저장하지 않는다.
- 새 이미지 에셋이나 의존성은 없다. 실은 최대 3개, 각 65개 점이며 대형 텍스처를 매 프레임 업로드하지 않는다.
- 개발 서버에서 `?pad=flower&fibers=1`로 첫 판부터 확인할 수 있다. `fibers` 강제 생성 옵션은 프로덕션에서 무시한다.
- 공개 링크와 AIT에는 별도 승인 및 배포가 필요하다.
