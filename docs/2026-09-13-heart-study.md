# 패드 컬러·WebP 비즈 통합

기준 main `02fefe1`, 별도 브랜치 `codex/heart-material`. 첫 하트 재질 실험은 사용자 검토 후 철회했고, 현재 결과는 기존 패드의 모양·홈·개수·물리·젤 렌더를 유지한 통합안이다.

## 변경

- `gel/Material.ts`: 기존 반투명 합성과 입체 음영은 유지하고, 흰 무대에 합성될 때 회색으로 수렴하던 저채도 입력 팔레트만 봄 느낌의 맑은 색으로 조정했다. 기본 11종과 변종 패드에 모두 적용된다.
- `beads/BeadAssets.ts`: 새 유리·진주·하트·금색 보석 WebP를 패드 전용 스킨이 아닌 해당 비즈 타입의 공용 재질로 연결했다. 사전 로드·캐시하며 실패하면 기존 사진, 다시 실패하면 절차적 렌더러를 사용한다.
- `beads/Bead.ts`: 새 진주가 같은 크기와 방향으로 몰려 보이지 않도록 표면 진주는 최대 4개로 제한하고, 기존 반경 범위 안에서 크기를 분산했다. 진주끼리만 추가 간격을 둔다. 사진 비즈는 개체별 회전을 부여하되 원형 유리·진주는 주광원이 깨지지 않는 작은 범위, 금속과 모양 비즈는 큰 범위로 회전한다. 화면 표시와 판정 반경은 동일하다.
- 금색 보석은 기존 `gold` ID에 연결했다. 희귀도·등장 확률·점수·수집 데이터는 바꾸지 않았다.

원본 PNG는 `art/beads/heart-study/`, 배포 파생본은 `public/assets/beads/studio-*.webp`다. 원본은 실제 알파가 있으며 이웃 물체나 배경 그림자가 없다. 상세 정보는 [원본·크롭·크기 표](../art/beads/heart-study/README.md)에 기록했다.

## 검증

- `pnpm run typecheck`, `pnpm run build`, `git diff --check` 통과. lockfile과 패키지 변경 없음.
- macOS 데스크톱 Chrome의 360/390/430×844 모바일 뷰에서 고정 개발 시드로 확인했다. 운영 생성 규칙에 시드 파라미터를 추가하지 않았다.
- 기본 패드 8종과 하트 렌더를 확인했다. 하트 비교 시 표면 28개·전체 38개로 기존 밀도를 유지했다.
- 같은 시드의 표면 진주 3개는 반경 15.35/16.82/17.46px, 회전 -0.38/-0.18/+0.28rad, 가장 가까운 외곽 간격 18.76px였다.
- DPR 2에서 실제 포인터로 잡기→POP→빈 홈→수집통 이동을 확인했다. 스튜디오 WebP 4개 요청, 실행 예외 0, 가로 넘침 없음.
- WebP 요청 차단과 WebGL 비활성화 조건에서도 기존 대체 이미지/Canvas 경로로 잡기→수집이 완료됐다.

증거: 작업공간 `output/playwright/rim-audio/hybrid-*.png`.

실기기 안드로이드/토스 WebView 검증은 아니며 모바일 60fps를 보장하지 않는다. main 머지·푸시·운영 배포는 하지 않았다.
