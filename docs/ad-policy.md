# 패드 전환 광고 설계

## 기본 규칙

- 첫 패드를 플레이하는 동안은 광고가 없다. 첫 패드 완료 후 NEXT부터 모든 일반 패드 전환이 전면광고 후보가 된다.
- 광고 준비 실패·no-fill·표시 예외는 해당 전환을 소비하지 않아 다음 일반 NEXT에서 다시 시도한다.
- 보상형은 사용자가 ‘광고 보고 잡기’를 선택할 때만. 보상 획득 확인 시 희귀 변종, 취소/실패 시 일반 패드. 실패한 같은 전환에 전면광고를 추가하지 않는다.
- 희귀 패드의 보상형 광고는 그 전환의 전면광고를 대체한다. 그 다음 일반 패드 전환부터 다시 전면광고를 노출한다.
- 완료 연출(별 1.15초) 이후 1.2초에 NEXT를 열고 사용자 클릭으로만 실행. 마지막 POP 순간에 자동 표시하지 않는다.
- 설정/컬렉션/앱 시작에는 호출하지 않는다. 향후 발견 패드 선택은 이 NEXT 경로와 분리한다.
- 광고 준비가 안 됐으면 즉시 진행. 실행 예외도 진행. 중복 클릭은 잠그며 한 번만 패드를 연다.

## 현재 구현과 SDK 경계

`createAdProvider()`는 토스 광고 API(`loadFullScreenAd`/`showFullScreenAd`)를 지원하는 환경이면 `TossAdProvider`를, 아니면 `MockAdProvider`를 쓴다.

- **TossAdProvider**: 앱 시작 때 전면(`ait.v2.live.fd15b48eec824769`)·보상형(`ait.v2.live.9a6ebffe05904cda`) 광고를 한 개씩 미리 로드하고, 노출이 끝나면 다음 광고를 다시 로드한다. 로드 실패는 15초 뒤 재시도한다. ready는 사전 로딩 상태를 동기 반환하며 NEXT에서 광고 로딩을 기다리지 않는다. show는 `dismissed` 뒤 완료하고, 보상형은 `userEarnedReward` 이벤트를 받은 경우에만 rewarded를 반환한다. `failedToShow`/예외는 unavailable로 즉시 진행한다.
- **MockAdProvider**(일반 브라우저·로컬): 전면광고는 항상 unavailable로 즉시 진행하며 실제 광고 화면/노출/매출은 없다. 희귀 변종은 모의 보상 성공으로 열린다. 모의 성공도 테스트용 빈도 제한에는 반영되지만 실제 노출 지표로 집계하면 안 된다.

아직 실기기에서 확인하지 않은 것: 광고 도중 사운드/게임 입력 정지·복구, 백그라운드 복귀, 동의/연령 정책, 실제 fill률과 매출.

모든 제공자에 걸리는 60초 watchdog은 abort를 전달하고 게임을 진행시킨다. 어댑터는 abort 시 광고가 뒤늦게 뜨지 않도록 취소하고 이미 열린 오버레이도 정리해야 한다. 이 계약을 지원하지 않는 SDK는 그대로 연결하지 않는다. 60초는 광고 길이 약속이 아니다.

별도 저장 키 `ssok.ads.v1`: lastAdCompleted. 예전 `skipNext`·`lastAdAt` 데이터가 있어도 오류 없이 새 매판 정책으로 넘어간다. 진행/보물 저장은 수정하지 않는다. 저장 차단 시 메모리 정책으로 계속 동작한다.

## 운영 실험 (아직 수집하지 않음)

SDK 연결 이후 consent를 고려해 NEXT 요청, 정책 스킵 사유, 실제 노출/닫힘/보상, 다음 패드 시작을 구분한다. 모의 성공을 실제 노출로 세지 않는다. 광고 직후 이탈·다음 판 시작률·재방문·사용자당 실제 수익을 함께 비교해 매판 정책의 이탈 영향을 점검한다. 수익 개선은 아직 검증되지 않았다.

검증: `pnpm test`(`tests/ad-policy.mjs` 포함), `pnpm build`. PR마다 CI가 같은 명령을 실행한다.

현재의 **첫 패드 뒤 매 전환** 정책은 `tests/ad-policy.mjs`에서 첫 NEXT부터 연속 노출, 희귀 보상형 뒤 다음 일반 전환, no-fill/오류 복구를 검사한다. 실기기/실광고/매출은 별도 검증이 필요하다.

수정 파일: `ads/AdPolicy.ts` 정책/제공자, `ui/App.tsx` NEXT 연결·연타 잠금·연출 대기, `Game.ts`와 `pads/progress.ts`의 이전 보상형 전용 연결 제거, `tests/ad-policy.mjs` 정책 회귀 검사, README 및 이 문서. 젤·비즈·저장 진행·보상 확률은 변경하지 않았다.
